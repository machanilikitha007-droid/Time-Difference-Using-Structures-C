# Time Difference Using Structures in C

## Project Description

A simple C program that uses a structure to store two time values and calculate the difference between them.

## Features

- Enter start time
- Enter end time
- Calculate time difference
- Display the result

## Technologies Used

- C
- Structures
- Arithmetic Operations

## How to Run

Compile and run the `time_difference.c` file using a C compiler.
